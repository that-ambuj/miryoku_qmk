KEY COMBINATIONS & ACCESS
=========================

Layer Access:
- NAV layer: Hold left thumb (Tab)
- MOUSE layer: Hold right thumb (Enter)
- SYMBOL layer: Hold right thumb (Space)
- NUMBER layer: Hold right thumb (Backspace)
- MEDIA layer: Hold both left thumbs (Tab + Enter)
- FUNCTION layer: Hold both right thumbs (Space + Backspace)
- BUTTON layer: Hold corner keys (Z or /)

Thumb Combos:
- Left combo (Tab + Enter): ESC / MEDIA layer
- Right combo (Space + Backspace): DEL / FUN layer
- NAV layer combo (Tab + Backspace): Delete when in NAV layer
- FUN layer combo (Tab + Enter): APP menu when in FUN layer

Special Keys:
- RESET: Double-tap top-left key (Q position) in any layer
- BTN = Button layer access (clipboard functions)
- AGR = AltGr modifier for special characters
- CTL/ALT/GUI/SFT = Home row modifiers

Flash Commands:
- Left half:  qmk flash -kb ferris/sweep -km manna-harbour_miryoku -bl avrdude-split-left
- Right half: qmk flash -kb ferris/sweep -km manna-harbour_miryoku -bl avrdude-split-right
